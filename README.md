# Clean Kindle Clock

This turns a Kindle running KUAL into a pretty clock with a little bit of weather info.
Also, this a fork of mattzw/kindle-clock. Go check that out, too!
Disclaimer: This has only been tested on a Paperwhite 10th Gen.

# What you need
1. a Kindle running KUAL.

2. a (Micro-USB/USB-C depending on version) Cable

3. a computer (obviously)
# How To Install
1. Unzip clean-kindle-clock.zip.

1.2. Connect your Kindle with KUAL.

2. Go into the extensions folder, and put the unzipped folder into there.

3. Eject your Kindle

4. Done!
